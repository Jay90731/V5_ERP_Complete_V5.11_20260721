# 婚約訂單 V6 統一資料庫操作說明

## 唯一資料庫

所有功能只使用：

`data/orders.db`

網站、人工修正、每日 7 天掃描及最近 6 個月掃描不再各自保存可寫資料庫，也不需要同步排程。

## 啟動網站

1. 將 ZIP 完整解壓縮到 ERP 電腦本機資料夾。
2. 雙擊 `START_WEDDING_ORDERS_WEB.bat`。
3. 網站會開啟 `http://127.0.0.1:8765/`。
4. 網站上方會顯示資料庫檔名與最後更新時間；按重新整理按鈕即可看到掃描或人工修正後的資料。

## 執行 ERP 掃描

1. 先關閉 Excel 等可能占用結果的程式。
2. 雙擊 `START_DAILY_AND_6_MONTHS.bat`。
3. 選擇「開始每日 7 天流程」或「開始最近 6 個月流程」。
4. 依原流程人工登入 ERP，登入後按繼續。
5. 截圖與 OCR 完成後，程式先備份 `orders.db`，再使用共用寫入服務更新資料庫。
6. 網站按重新整理即可看到最新資料。

兩種掃描不可同時執行；網站人工修正若遇到掃描正在寫入，會顯示「資料庫正在更新，請稍後重試」。請等待該次寫入完成後重試，不要複製或另建資料庫。

## 待確認人工處理

1. 網站選擇「待確認」。
2. 開啟原圖並修改主檔與完整多品項。
3. 選擇確認寫入、標記不納入或暫時保留。
4. 每次動作前會自動建立可驗證備份，失敗時整筆 rollback。

## 圖片保留

- 第一次部署後雙擊 `INSTALL_7_DAY_IMAGE_CLEANUP.bat` 安裝每日清理排程。
- 只有已成功辨識、超過 7 天且未受保護的圖片可以刪除。
- 待確認圖片在處理完成前永不刪除；處理後仍至少保留 7 天。
- 清理程式不會刪除 SQLite、待確認資料或 R6 不可變備份。
