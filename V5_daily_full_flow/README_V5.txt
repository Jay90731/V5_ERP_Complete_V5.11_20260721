婚約訂單 V5 一鍵每日完整流程

日常執行：
1. 雙擊 RUN_V5_DAILY.bat。
2. 按「開始每日流程」。
3. ERP 登入畫面出現後，人工輸入帳號密碼並完成登入。
4. 回到 V5 視窗，按「登入完成，繼續」。
5. 等待七個階段完成，最後可按「開啟 Excel」或「查看紀錄」。

停止與續跑：
- 執行中按「停止」，工具會在安全點停止，不會更新正式歷史或 Excel。
- 重新開啟後按「繼續未完成流程」。已完成訂單依訂單編號跳過。
- STOP_V5_NOW.bat 是控制視窗無法操作時的備用停止入口。

安全規則：
- ERP 帳號密碼只由使用者人工輸入，工具不保存。
- ERP 只進行查詢、清單切換與截圖，不操作新增、修改、刪除、儲存或列印。
- 截圖、OCR、驗證、比較全部成功後，才以交易方式更新正式歷史與 4001 Excel。
- 同時只能執行一個 V5。
- 每次執行資料位於 runs\日期\run_時間；daily_summary.txt 是每日摘要。

測試入口：
- CHECK_V5_ENVIRONMENT.bat：檢查 ERP、Python、Node、OCR 與正式狀態。
- RUN_V5_SAME_DAY_REPLAY_TEST.bat：以相同六個月資料驗證新增 0、已變更 0。
- 同日測試完成後，same_day_replay_verification.json 會記錄歷史版本、異動紀錄及 Excel 的前後比對。

部署提醒：
- 正式 ERP 流程必須在 ERP 電腦本機執行。
- 若換到另一台 ERP 電腦，先準備 runtime 資料夾或修改 v5_config.json 的執行環境路徑。
